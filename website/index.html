功能特性

六大实用命令，覆盖日常开发与系统管理常见需求

MD5 哈希

快速计算任意文本的 MD5 哈希值，支持多词参数自动拼接。

platinum md5 "Hello World"

BMI 计算

输入身高（厘米）和体重（千克），自动计算 BMI 并给出健康评估。

platinum bmi 175 70

随机数生成

生成指定范围内的随机整数，默认范围 0-100，支持自定义边界。

platinum random --min 1 --max 100

待办管理

本地持久化的待办事项管理，支持添加、完成、删除和清空操作。

platinum todo add "购买牛奶"

大小写转换

一键将文本转换为大写或小写，支持多词参数。

platinum case upper "hello world"

UUID 生成

生成符合 RFC 4122 标准的 UUID 字符串，适用于数据库主键和标识符。

platinum uuid

快速开始

三步上手，即刻体验

1
下载程序

前往 GitHub Releases 下载最新版本的 platinum.exe

github.com/IceWars1o1/Platinum/releases
2
配置环境

将 platinum.exe 所在目录添加到系统 PATH，或直接使用完整路径运行。

# 推荐：添加到系统环境变量
setx PATH "%PATH%;C:\Tools\Platinum"
3
开始使用

打开 CMD 或 PowerShell，输入命令即可使用。

$ platinum --version
$ platinum md5 "Hello World"
$ platinum todo add "第一个任务"

命令参考

完整的命令用法与参数说明

全局选项

-v, --version 显示版本信息
-h, --help 显示帮助信息
md5 计算 MD5 哈希值
platinum md5 <text>

计算给定文本的 MD5 哈希值。支持多词参数，自动以空格拼接。

bmi BMI 计算
platinum bmi <height_cm> <weight_kg>

根据身高（厘米）和体重（千克）计算 BMI，并输出健康分类。

random 随机数生成
platinum random [--min <N>] [--max <N>]

生成指定范围内的随机整数。默认范围 0-100。

todo 待办事项管理
platinum todo add "<item>" — 添加待办
platinum todo list — 列出所有待办
platinum todo finish — 标记完成（交互式）
platinum todo remove — 删除待办（交互式）
platinum todo clear — 清空所有待办
case 大小写转换
platinum case <upper|lower> "<text>"

将文本转换为大写（upper）或小写（lower）。

uuid UUID 生成
platinum uuid

生成符合 RFC 4122 标准的 UUID 字符串。
